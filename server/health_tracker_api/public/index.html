Body Ledger

A personal health tracking system built on an append-only event ledger.

No deletes, no overwrites, full audit trail. Offline-first across all clients. Self-hosted — no third-party cloud, no lock-in.

Design Principles

  • Immutable ledger — health events are never modified or deleted. Corrections are amendment events that reference the original. Current state is always computable from the full log.
  • Thin clients — clients record raw events and render results. All business logic lives in Rails. One correct implementation, applied everywhere.
  • Offline-first — every client buffers to local SQLite and syncs when connected. The append-only model makes sync almost always additive.
  • Full data ownership — self-hosted on your own server.
